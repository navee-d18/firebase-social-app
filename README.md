# 🌌 Nexus AI: Futuristic Social Productivity Platform

**Nexus AI** is a premium, high-end social productivity ecosystem designed with a cinematic, futuristic aesthetic. It combines the community power of Discord, the real-time communication of Instagram/WhatsApp, and the productivity tools of Notion—all powered by an integrated AI core.

![Project Status](https://img.shields.io/badge/Status-Advanced_Beta-green?style=for-the-badge)

## ✨ Core Features

### 🚀 1. Command Center (Dashboard)
- **Cinematic Visualization**: A high-end data dashboard with real-time stats.
- **Gamified XP System**: Track your productivity with levels and experience points.
- **AI Daily Briefing**: Simulated AI insights for your day.

### 📝 2. AI Intelligence Notes (Notion-Style)
- **Markdown Support**: Full-screen premium markdown editor.
- **AI Toolkit**: Integrated buttons to Summarize, Fix Grammar, and Generate Titles.
- **Dual Mode**: Seamlessly switch between Writing and Previewing.

### 🛠️ 3. Productivity Hub (Tasks & Kanban)
- **Dual View**: Switch between a classic Todo List and a professional **Kanban Board** (To Do, In Progress, Done).
- **AI Task Brainstorm**: One-click "AI Brainstorm" to generate tasks based on your workspace title.
- **Priority System**: Cycle through Low, Medium, and High priority tags.

### 💬 4. Nexus Chat (Social DM)
- **Instagram/WhatsApp Hybrid**: A clean, pill-shaped bubble UI with circular avatars.
- **True Black Aesthetic**: Optimized for OLED screens with subtle glassmorphism.
- **Real-time Sync**: Instant messaging with "Seen" indicators and online status.

### 🏛️ 5. Community Nexus (Discord Server Style)
- **Multi-column Interface**: Discord-inspired 3-column layout for groups.
- **Channels & Hubs**: Organized channels like `#general`, `#announcements`, and `#ai-assistance`.
- **Member Registry**: Real-time member list with rank/level badges.

### 👤 6. Identity Dashboard (Profile)
- **Social Profile**: Premium banner and avatar UI.
- **XP Progress visualization**: A glowing progress bar showing your journey to the next level.
- **Achievement Badges**: Showcase earned badges like Pioneer, Sage, and Active Citizen.

## 🛠️ Tech Stack

- **Frontend**: [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Custom Glassmorphism + Dark Mode)
- **Database & Auth**: [Firebase v9+](https://firebase.google.com/) (Firestore Real-time)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **State Management**: [Context API](https://reactjs.org/docs/context.html)

## 🚀 Getting Started

### Prerequisites
- Node.js installed
- Firebase project created

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/nexus-ai.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file in the root and add your Firebase credentials:
   ```env
   VITE_API_KEY=your_api_key
   VITE_AUTH_DOMAIN=your_auth_domain
   VITE_PROJECT_ID=your_project_id
   VITE_STORAGE_BUCKET=your_storage_bucket
   VITE_MESSAGING_SENDER_ID=your_sender_id
   VITE_APP_ID=your_app_id
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
